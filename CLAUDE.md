# Wingman — notes for AI/dev sessions

Wingman is a conversation assistant ("wingman") that overlays reply/topic/guide suggestions inside
WhatsApp/Instagram for Roman Urdu/Hindi + English (code-mixed) texters.

**Start every session by reading `docs/HANDOFF.md`** — it holds the current phase, decisions taken,
open questions and the exact next steps. Update it before ending a session or when context is
running low.

Design docs (read in order, only what you need):
1. `docs/01-product-scope.md` — refined scope, personas, features, non-goals, metrics
2. `docs/02-tech-stack.md` — stack decisions (ADR-style)
3. `docs/03-system-design.md` — architecture, data model, APIs, pipelines
4. `docs/04-poc-implementation-plan.md` — POC milestones, tasks, acceptance criteria
5. `docs/05-production-roadmap.md` — POC → all platforms / integrations

Conventions:
- Clients: TypeScript. Backend: Python (FastAPI). Contract = OpenAPI generated by the backend.
- Local-first: raw chat history never persists server-side.
- LLM access only through the provider-agnostic gateway (`services/api/app/llm`).
- Never auto-send messages on any platform; the user always presses send.
